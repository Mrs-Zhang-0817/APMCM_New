# Git双人协作规范

main是共享稳定文档基线，不代表Pending科学决策已经批准。q1-spectral负责04_Q1光谱研究，q2-gas-oxygen负责05_Q2供氧与烟气研究；成员对应关系待确认。q3-fusion、paper在实际需要时才创建。用户于2026-11-27确认公开上传许可并授权发布现有研究基线。仓库保持公开，原始官方PDF/XLSB仍不提交；后续研究提交按任务范围、审核和许可要求执行。

00、01、02、03、06、07、08目录及根目录文件共同管理，重大修改先提案，由指定整合人处理。Q1/Q2不直接改对方成果。

开始前先git branch --show-current和git status --short，确认工作区干净；允许连接远程后git fetch origin。首次从main建立本线分支；后续在本线执行git merge main（有远程可先同步main）。发现未提交修改先整理提交或与作者协调，不盲目切分支覆盖文件。有冲突逐段核对来源和依据，不运行reset --hard、clean -fd或强推。

完成后检查git diff、必要验证、来源和证据、敏感信息及不相关修改；只暂存明确文件，提交到本线。本次公开发布已获用户授权，可推送已审查的main基线和两条研究分支；后续本线成果推送后通过Pull Request交叉审核。重大研究决定须两队员确认后由整合人合并main。

提交信息用英文类型加中文具体说明：docs: 建立项目规范；data: 更新十炉质量统计；analysis(q1): 完成65535邻域调查；analysis(q2): 完成零段调查；experiment(q1): 比较候选检测方法；fix(q2): 修正流率计算；review: 完成交叉审核；decision: 更新共同预处理方案；paper: 完善模型章节。每次只提交逻辑相关修改，不使用update/test等含糊描述。

PR必须列目标、Task ID、完成任务、修改文件、数学方法、数据与实验证据、验证结果、未决问题、队友需确认事项。PR审核不能代替两名队员科学决策。检查待合并版本、基线哈希和测试炉隔离，保留未解决分歧。未确认状态维持Pending。

main与两条研究分支以本次发布的共同基线为起点。此规范是团队约定，尚未配置GitHub保护分支或自动审批；不能假称平台已强制执行。
