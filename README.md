# 2026 APMCM Problem B：转炉双模态时序信息融合

两人团队研究炉口火焰光谱与供氧、烟气时序数据。Q1识别光谱异常并连续重构十炉光谱；Q2处理供氧与烟气序列，重构流率/累计量并研究随供氧流率变化的延迟；Q3利用Q1/Q2的模型和对齐证据，用光谱实时预测烟气并检验十炉泛化。具体解释以本队合法取得的官方题目为准。
