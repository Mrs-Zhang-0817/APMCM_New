# S01–S07运行与依赖

实际使用Python3.12；numpy2.5.5、pyxlsb1.0.10、matplotlib3.11.2、pymupdf2.2（实际版本以运行核验JSON为准）。已有独立项目依赖目录.analysis_deps通过PYTHONPATH使用，无新安装。代码不依赖个人绝对路径。
从原研究工作区根目录运行（其中Data/Data存原附件，附件1修正版与官方PDF在根目录）：
```
python APMCM_New/04_Q1光谱研究/代码/migration_preflight.py --corrected 附件1.炉号-6B03205.xlsb
python APMCM_New/04_Q1光谱研究/代码/spectral_investigation.py --source-root .
python APMCM_New/04_Q1光谱研究/代码/write_investigation_reports.py
```
若来源根目录有original与corrected子目录，读取器支持对应布局；官方PDF仍放source-root根目录。PYTHONPATH设为本机独立依赖位置，MPLCONFIGDIR设本机可写缓存，PYTHONIOENCODING=utf-8。报告不会上传原始数据。
迁移preflight通过AST提取历史load函数并实际执行，避免旧模块顶层重建v1共同文档。新程序实际重读十炉，与旧共享统计交叉核验。绘图与计算对应同一脚本，报告由CSV生成，不手填数值。
原始数据无写入操作，不保存完整原矩阵。阈值12/20/30、MAD系数1.4826、floor1、近上限60000、4/8邻域、局部窗口±5行/±20列全部是探索描述参数；没有随机实验，未来设计拟种子20261127尚未调用。
首次有语法错误已修复，重新运行；程序若研究成果/运行核验.json已存在会拒绝覆盖，应在新的明确版本工作目录重现，不能抹去已发布结果。历史预检实测和主程序哈希见研究成果文件；运行时间见JSON。
