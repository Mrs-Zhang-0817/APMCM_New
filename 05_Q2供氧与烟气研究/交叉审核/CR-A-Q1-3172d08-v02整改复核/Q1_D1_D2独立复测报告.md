## 试验与预期

确定性探针只使用人工数组。默认 `k=6`、`floor=1`、时间和波长半径各 2，除专门注明的同步缩放例。7×7 局部探针中心为零基 (3,3)，未指定单元填 NaN。所有给定邻点都在方法实际使用的同行或同列位置。扰动背景唯一随机种子为 `20261127`。分数为 `(x−median)/(1.4826×MAD+floor)`。

验收预期为按实际可用的有限邻居计数，每轴至少两点，污染政策冻结后另计未污染数。D1 至少一个可评估方向给出正证据即可触发，缺少另一轴时仅有的低分不应被默认为确认阴性。D2 需两方向均可评估且同号超阈值。一侧或两侧不可评估时留下明确状态。此为复测判据，等待双方共同冻结。

## 分母与回归验收

在 0+0 探针中，只把中心纳入评价。如果真值设为背景，直接传 `False` 给混淆矩阵会记 TN=1。如果真值设为注入点，会记 FN=1、Recall=0。若直接将中心从 eligible 剔除，两种情况都变成评价分母 0。应同时报告总数、可评估数、不可评估原因和未评估真阳性数，并为 D1/D2 报共同可评估集和各自覆盖。边界、缺失、污染、MAD=0、峰和连续块应分别报告 `TP/FP/FN/TN` 和覆盖率。单看可评估子集的 F1 无法发现丢失困难点。

后续以同一输入对照旧版与新版，记录每个观测点的旧/新预测和可评估状态，保证边界合规样本与完整背景仍可评估。高幅噪声或真实工况的误伤与漏检仍须依后续获批的参考用途与独立验证方案判定。本轮未运行真实检测器。

## 最小复跑代码

把下列脚本放在独立临时目录并设置 `PYTHONPATH` 指向固定快照的 Q1 `代码` 目录。脚本不读工作簿。全 NaN 方向的 NumPy 警告在展示分数时被局部过滤，NaN 本身保留。

~~~python
import warnings
import numpy as np
from validation_modules import detect, detection_metrics

seed = 20261127
params = dict(threshold=6, floor=1, time_radius=2, wave_radius=2)
center = (3, 3)
axis_t = [(1, 3), (2, 3), (4, 3), (5, 3)]
axis_w = [(3, 1), (3, 2), (3, 4), (3, 5)]

def local(tv, wv, v=12):
    x = np.full((7, 7), np.nan)
    x[center] = v
    for position, value in zip(axis_t, tv):
        x[position] = value
    for position, value in zip(axis_w, wv):
        x[position] = value
    return x

def run(x, k, floor=1):
    with warnings.catch_warnings():
        warnings.filterwarnings("ignore",message="All-NaN slice encountered")
        return detect(x, k, **dict(params, floor=floor))

def fmt(v):
    return f"{v:.6f}" if np.isfinite(v) else "NaN"

def probe(name, x, pos=center, floor=1):
    cells = []
    for k in ("D1", "D2"):
        p, scores = run(x, k, floor)
        cells.append(f"{int(p[pos])} / {fmt(scores['time_score'][pos])} / {fmt(scores['wave_score'][pos])}")
    print(name, *cells, sep=" | ")

probe("1+1", local([0],[0]))
probe("2+2", local([0,0],[0,0]))
probe("2+1", local([0,0],[0]))
probe("2+0", local([0,0],[]))
probe("0+0", local([],[]))
probe("MAD0-original", local([100]*4,[100]*4,101))
probe("MAD0-fixed-floor-rescaled", 100*local([100]*4,[100]*4,101))
probe("MAD0-co-scaled-floor", 100*local([100]*4,[100]*4,101),floor=100)
probe("clean-control", local([100,100,102,104],[100,100,102,104],140))
probe("65535-neighbors", local([100,102,65535,65535],[100,102,65535,65535],140))
edge=np.zeros((7,7))
edge[0,0]=12
probe("boundary",edge,(0,0))

persistent=np.full((15,25),100.)
persistent[:,12]=1000
transient=np.full((15,25),100.)
transient[7,12]=1000
block=np.full((41,61),100.)
block[10:31,15:46]=300
background=100+np.random.default_rng(seed).uniform(-1,1,(15,25))
for k in ("D1","D2"):
    print(k, "persistent", int(run(persistent,k)[0][:,12].sum()), "/15",
          "transient",int(run(transient,k)[0][7,12]),"/1",
          "block",int(run(block,k)[0][10:31,15:46].sum()),"/651",
          "block-total",int(run(block,k)[0].sum()),"/2501",
          "background",int(run(background,k)[0].sum()),"/375")
    sparse=local([],[])
    p,_=run(sparse,k)
    singleton=np.zeros_like(p)
    singleton[center]=True
    for is_candidate in (False,True):
        truth=singleton & is_candidate
        included=detection_metrics(p,truth,eligible=singleton)
        omitted=detection_metrics(p,truth,eligible=np.zeros_like(singleton))
        print(k, "unsupported-metrics", is_candidate, included, omitted)
~~~
