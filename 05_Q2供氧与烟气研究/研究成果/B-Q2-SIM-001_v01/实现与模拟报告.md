## 查询与数学定义

时间为炉次相对秒，保持原 Sequence 轴。输入时间必须严格递增，函数只定义在各自首、末有效输入节点构成的闭区间。支持标量和数组任意域内时刻查询。非有限、域外查询、反向积分区间、非单调累计氧、负烟气流率或超配置跨度均报错。端点流率按域内一侧导数解释。函数用于离线重构，区间支撑可以用到目标时刻后的节点。

| 对象 | 实现与连续阶 | 单位与守恒 |
| --- | --- | --- |
| 累计供氧 `O(t)` | 分段三次，节点共用导数，为 (C^1)。通过原输入节点。绝对累计量锚在首观测值。 | m³。任一区间供氧量为 `O(b)−O(a)`。 |
| 氧枪流率 `q(t)` | `O′(t)`，分段二次，连续 (C^0)，保证非负。保持段的模型流率为零，解释需独立工艺证据。 | m³/s。每个输入区间的 `∫q dt` 等于对应累计氧增量。 |
| CO₂、CO 流率 | 分别以节点值构造非负线性段，流率连续 (C^0)。 | m³/s。域内峰值可被节点间线性近似压低。 |
| 两种累计排放 | 分别解析积分其线性流率，为分段二次 (C^1)。从各自输入窗的首节点取 0。 | m³。节点累计增量与同窗梯形积分一致，窗外排放不计。 |

对氧气段，设长度 `hᵢ`、平均流率 `dᵢ=(Oᵢ₊₁−Oᵢ)/hᵢ`、归一化坐标 `u=(t−tᵢ)/hᵢ`。把节点候选导数限制在非负且不超过其相邻 `d` 最小值的 1.5 倍。取二次 Bernstein 系数 `mᵢ, 3dᵢ−mᵢ−mᵢ₊₁, mᵢ₊₁`。三系数非负且均值为 `dᵢ`，所以积分既单调又守恒。共同节点共享 `m`，实现连续流率。真实阶跃的连续近似会展宽转折，守住累计量也可能误估瞬时峰值。

## 连续函数模拟实得

解析输入为 `O=4+2t+0.05t²`、`q=2+0.1t`、`CO₂=1+0.6·max(t−5,0)`、`CO=0.8+0.2t`，烟气真累计为相应闭式积分。0–12 s，12 个非均匀输入节点、1,201 个检测时刻。三条流率到真值的最大绝对误差不超过 (4.45×10^{-15}) m³/s，累计量误差不超过 (7.11×10^{-15}) m³。对 11 段各自用两点 Gauss 求积，最大的守恒误差为 (1.78×10^{-15}) m³，独立子区间可加性误差最大 (3.56×10^{-15}) m³。中心差分独立核对导数，离节点误差最大 (4.76×10^{-10}) m³/s，CO₂ 折点处约 (1.50×10^{-6}) m³/s，由差分跨越斜率变化造成。

压力测试使用原 0.5 s 网格的 25 个节点，逐场景仍在 1,201 个时刻比对原解析真值。

- 保持情景的氧累计相邻重复为 16/24。保持模拟端点增量恰好与真值同为 31.2 m³，氧流率仍有 3.5393 m³/s 的 MAE。量化情景守住记录端点的 31.0 m³，真实端点增量为 31.2 m³。
- 真零区用有明确双边界的非负线性流率生成，3–6 s 的 301 个查询点保持零。若将原本非零的 7/25 个 CO₂ 采样人为置零，零段流率 MAE 为 1.1007 m³/s，窗末累计偏差为 −3.95 m³。这个模拟解释为何真实零值应保留为观测，其物理机制另审。

## 时延模拟实得

扫描 `Corr(x[i],g[i+k])`，正 `k` 表示氧领先。使用同一批氧索引对照所有候选滞后，避免变长重叠抬高某个峰。合成试验间隔 0.5 s，120 s 半开窗口，240 节点，种子 20261127，搜索 −20 至 +20 s。水平和线性去趋势用 160 对共同样本，一阶差分用 159 对。低方差、激励集中、峰相关不足、竞争峰太近或峰落搜索边界时，输出不可辨识及原因。诊断峰和可报告时延分别记录。

激励集中度用去均值能量占比 `wᵢ=zᵢ²/Σz²`，有效激励数为 `1/Σwᵢ²`。这衡量能量是否集中在少数配对点，和独立事件数不同。单跳变构造的有效激励约 1.01，未达到模拟门槛 6。

| 构造 | 真时移 s | 实得 |
| --- | ---: | --- |
| 低供氧水平 5，CO₂ / CO | +8 / +6 | +8 / +6 s |
| 高供氧水平 9，CO₂ / CO | +5 / +4 | +5 / +4 s |
| 气体领先对照 | −4 | −4 s |
| 网格间时移 | +4.25 | +4.5 s，误差 +0.25 s |
| 异步保持 | +8 | 原值 +8.5 s。差分峰相关约 0.36，拒报。 |
| 共同线性趋势 | +8 | 原值峰相关接近 1，竞争峰差仅约 0.00131，拒报。差分及线性去趋势均为 +8 s。 |
| 只有同步阶跃 | 无设定运输关系 | 激励集中，拒报。 |
| 多点共同驱动 | 无设定运输关系 | 仍得到 0 s 统计时移。说明真实物理因果需要独立依据。 |
| 低激励 / 气体常量 | +8 | 两者均拒报，原因是激励不足。 |
| 周期等价峰 / 搜索边界 | +1.5 / +20 | 分别报告竞争峰歧义和边界峰，均拒报。 |

两个供氧档的时延是模拟设定。现有扫描仅估计统计时移，仪器保持、传感器响应、共同驱动与运输会共同影响结果。扫描网格之外无亚步长精度承诺。较短窗另触发共同样本不足。
